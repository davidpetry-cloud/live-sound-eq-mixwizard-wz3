# Live Sound EQ — Allen & Heath MixWizard WZ3 16:2

A self-contained, single-page web tool for live sound EQ reference on the
Allen & Heath MixWizard WZ3 16:2 mixer.

## Live demo

https://davidpetry-cloud.github.io/live-sound-eq-mixwizard-wz3/

## Usage

Open `index.html` directly in a browser, or visit the live demo link above.
No build step or server is required — everything needed to run the page is
bundled into the single HTML file.
